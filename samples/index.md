# Beispiel-Handbuch

Willkommen! Diese kleine Dokumentation zeigt, was der **MarkDown Viewer** kann.
Klicke auf einen Link, um tiefer zu gehen – mit **Zurück** (`Alt+←`) kommst du wieder hoch.

## Inhalt

1. [Grundlagen](kapitel/grundlagen.md) – Text, Tabellen, Code und Aufgabenlisten
2. [Diagramme](kapitel/diagramme.md) – Mermaid, SVG und Formeln
3. [Ein defekter Link](kapitel/gibt-es-nicht.md) wird rot markiert
4. Externe Links öffnen im Browser: [Avalonia](https://avaloniaui.net)
